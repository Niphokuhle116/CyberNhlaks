NETWORK RECONNAISSANCE

Nmap Network Reconnaissance

A hands-on network reconnaissance laboratory focused on host discovery, port scanning, service enumeration and security analysis.

Nmap Kali Linux Networking Reconnaissance

01 — OBJECTIVE

Project Objective

The objective of this laboratory was to develop practical network reconnaissance skills using Nmap in an authorized lab environment.

The investigation focused on identifying live hosts, discovering open ports, determining available services and interpreting the results from a defensive security perspective.

02 — LAB ENVIRONMENT

Laboratory Environment

Operating System

Kali Linux

Primary Tool

Nmap

Target

Authorized laboratory host

Focus

Network reconnaissance

03 — METHODOLOGY

Reconnaissance Methodology

01

Host Discovery

Identify hosts that are reachable within the authorized laboratory network.

02

Port Scanning

Identify open TCP ports and determine which services may be accessible.

03

Service Enumeration

Determine the services and versions associated with discovered ports.

04

Security Analysis

Analyze the discovered attack surface from a defensive security perspective.

04 — NMAP COMMANDS

Commands Used

Basic Host Discovery 

nmap -sn TARGET_IP

Used to determine whether hosts are responding without performing a full port scan.

Basic Port Scan 

nmap TARGET_IP

Used to identify commonly scanned open TCP ports on the authorized target.

Service Version Detection 

nmap -sV TARGET_IP

Used to identify services and their detected versions.

Operating System Detection 

nmap -O TARGET_IP

Used in the laboratory to attempt operating system identification.

07 — LESSONS LEARNED

Lessons Learned

  • Network reconnaissance provides visibility into exposed systems and services.
  • Open ports should be investigated to determine whether the associated services are required.
  • Service enumeration can provide useful information for vulnerability assessment and defensive monitoring.
  • Reconnaissance should only be performed against systems where authorization has been provided.
